# kareemheshaam.github.io

My portfolio site. Next.js App Router, statically exported to GitHub Pages.

Live at [kareemheshaam.github.io](https://kareemheshaam.github.io).

## Stack

Next.js 16 (App Router, `output: "export"`), TypeScript, Tailwind CSS, Lucide icons. No runtime backend — everything ships as static HTML.

## Running it

Node.js 22 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

`npm run build` writes the static site to `out/`.

## Editing content

All copy — bio, experience, projects, skills, references, resume — lives in `data/site.ts`. Both the site and the printable resume at `/resume` read from it, so the two can't drift apart.

The PDF at `public/Kareem-Hesham-Resume.pdf` is generated by printing `/resume` to PDF. Keep the filename stable; it's linked from the site.

## Deploying

Pushing to `main` triggers `.github/workflows/deploy.yml`, which lints, typechecks, builds, and publishes to Pages. Repository **Settings → Pages → Source** is set to **GitHub Actions**.

Because this is a GitHub user site served from the domain root, no `basePath` is needed.
